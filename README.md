# 🎮 Tic Tac Toe Game

A simple and interactive Tic Tac Toe game built using **HTML, CSS, and JavaScript**.

---

## 🚀 Features

* ✅ Two Player Game (X vs O)
* ✅ Winner Detection
* ✅ Draw Detection
* ✅ Reset Game Option
* ✅ New Game Button
* ✅ Clean & Modern UI

---

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript

---

## 🌐 Live Demo

👉 https://vikaspawar-dev.github.io/tic-tac-toe-game/

## 📸 Preview

A simple Tic Tac Toe board where two players can play turn by turn and the game automatically detects the winner or draw.

## 📂 How to Run Locally

1. Download or clone this repository
2. Open `index.html` in your browser
